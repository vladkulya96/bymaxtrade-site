## Как выложить новую версию

1. Правки вносить в `site/` репозитория.
2. `scripts/make-hosting-zip.sh` → архив в `releases/`.
3. cPanel → File Manager → `public_html` → Upload → Extract с заменой. Служебные файлы хостинга не удалять: `.well-known`, `.403h.shtml`, `.404h.shtml`, `.user.ini`, `php.ini`, `cgi-bin`.
4. Для одной-двух правок проще открыть файл в File Manager → Edit (кодировка utf-8) и сразу повторить правку в репозитории.
5. Проверить оба языка в инкогнито.
