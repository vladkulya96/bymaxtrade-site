## Форма контакта
- Все кнопки «Request information» / «Request a quote» ведут в блок «Contact» перед подвалом.
- Поля: Company name, Contact number (с кодом страны, 7–15 цифр), E-mail, Message (10–600 символов, счётчик). Подсказки под полями, скрытое поле от роботов, согласие со ссылкой на политику.
- Кнопка WhatsApp: чат +386 70 247 352, в первое сообщение подставляются компания и начало текста формы (до 320 символов).
- Отправка через Web3Forms (ключ в `config.js`); без ключа — запасной режим mailto.

## 3D-путь партии («Эпоха парусников»)
- Порядок: плантация → порт происхождения (погрузка) → море → Копер, выгрузка → транзитное хранение → карта морских путей к нашим портам (камера в конце приближается к Европе) → новое фото склада.
- Переходы прямыми склейками, без облаков и дымки (решение 5.10). Изометрия сверху, узкий объектив; на карте обычный.
- Плантация: бенефисио с охристой черепицей, 3 площадки сушки, фермеры с корзинами, двое ворошат зерно, грузчики носят мешки в контейнер, второй контейнер уезжает в порт; ягоды красные. Футболки без логотипа.
- Склад в Копере: мешки на паллетах одинаковой укладки разной высоты, три блока в центре, паллеты вдоль стен, биг-беги в два яруса; у контейнера рукопожатие и человек с дипломатом, грузчики, лента, укладчик; ворота, тентованная фура, второй погрузчик, учётчик.
- Погрузчики ездят по плавным траекториям, корпус по ходу движения, разворот задним ходом.
- Логотип на гобелене склада без штриховки, в фирменных цветах.
- Анимации идут и при «уменьшить движение».

## Оптимизация для телефонов (состояние 7.10, потом изменено 28.10)
- Причина подвисаний: три прохода за кадр, на складе ~5,6 млн треугольников за проход.
- Сделано для экранов < 760 px и сенсорных < 820 px: мешки легче (484 треугольника вместо 1800), кусты и ягоды проще; тени PCF вместо VSM, пересчёт через кадр; в покое перерисовка вдвое реже; автоснижение разрешения; сглаживание канваса отключено.
- 28.10: плотность картинки на телефоне поднята до ×2,5 (автоснижение не ниже ×1,5), мягкие тени 2048, полная геометрия мешков и ягод; 25.10: скрытые мешки не рисуются, тени раз в три кадра.
- Резерв, если тяжело: убрать часть паллет и людей на телефоне, отключить тени, статичный кадр склада; сначала снизить `PR0` в `film.js` до ×2.

## Решения и правила
- Главный посетитель — обжарщики; мелкие трейдеры тоже клиенты. Сайт прежде всего функциональный.
- Логотип полностью, с D.O.O., только в фирменных цветах; на предметах (кружка, футболки) не ставить.
- Красный только у кофейных ягод.
- Не упоминать штат (директор и менеджер по продажам); в иллюстрациях консалтинга людей нет.
- Консалтинг без цен; оговорка MiFID II / ZTFI-1; услуги совпадают с договором и Annex 4.
- Тексты — английские карточки Влада без изменений; новые короткие подписи UI допустимы. С Weblium ничего не берём.
- Языки SI и EN; почта export@ (заявки) и manager@.
- Только порты прибытия: Trieste, Koper, Antwerp, Hamburg, Tallinn, Gdańsk. Склады не выделять; Риеку, Pacorini не упоминать. Число «six / 6» нигде (факт «3 seas»).
- Telegram пока нет; в планах канал новостей с платной подпиской до $5/мес.

## Идеи на потом
- Блок отзывов клиентов: только реальные, с согласием, без фраз о заработке (MiFID II); в «Эпохе парусников» — «письма корреспондентов» с печатью; место после услуг, перед оговоркой MiFID.
- GA4 только вместе с баннером cookie и обновлением политики.
- «Торговый дом»: двуязычный по той же схеме, если будет выбран.

## Структура для быстрой правки текстов
- `index.html` / `en/index.html` — только текст и разметка (~30 КБ). Стили `assets/css/style.css` (и `privacy.css`), скрипты `assets/js/` (page.js, form.js, film.js, three.min.js), картинки `assets/img/` (hero-warehouse.jpg, journey-photo.jpg, engraving-desk.jpg, logo-*.webp, map-*.png, иконки, og.jpg). Тексты скриптов — в блоке `window.MTL = { … }` в начале каждого `index.html`.
- Одностраничные превью (`previews/`) только для просмотра без хостинга; при открытии одного `index.html` из мессенджера страница без оформления — это нормально.
- `.services{overflow-x:clip}` — исправление бокового люфта на телефонах 320–414 px.
