# BY MAXTRADE d.o.o. — «Эпоха парусников»

Двуязычный (SI на `/`, EN на `/en/`) статический сайт с 3D-роликом по прокрутке (three.js r128).

- `site/` — готовый сайт, выкладывается на хостинг как есть (сборка не нужна). Движок сцены: `site/assets/js/film.js`. Настройки формы: `site/config.js` (ключ Web3Forms).
- `docs/` — инструкция для веб-мастера, файл для вычитки словенского, README пакета, передаточная записка от 25.10.2026.
- `previews/` — одностраничные файлы для просмотра без хостинга.
- `artifacts/age-of-sail-live.html` — копия опубликованной страницы-артефакта.
- `tools/` — скрипты правок движка (`patch_film.py`, `port_oct25.py`) и проверки (`snap.js`, `errs.js`, нужен Playwright).

Правило: тексты берутся только из английских карточек владельца; логотип только в фирменных цветах; число «six/6» не использовать.
Открыто: ключ Web3Forms; вычитка словенского носителем; проверка политики юристом; тест на реальных телефонах.
